# Changelog

All notable changes to StrainScope are recorded here, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/), where version numbers look like `MAJOR.MINOR.PATCH`. A new MINOR version marks a new usable level of the project (see the tags in [`docs/ROADMAP.md`](docs/ROADMAP.md#version-tags)), a PATCH marks a fix or a documentation improvement, and 1.0.0 marks the first complete release.

Each step is explained in [`docs/HANDBOOK.md`](docs/HANDBOOK.md), the day-0-to-product guide that links to every phase guide.

## [1.0.0] - 2026-10-12: the first complete release

The first complete release: Phases 7, 7b and 8, and the fix of Handbook Stage 12.1. StrainScope runs online with nothing to install, explains its results in plain words, answers questions about its documents, data and graph, offers its results to AI assistant apps through an MCP server, rebuilds every result with one command, and is tested on Windows, macOS, Linux and RHEL 8 at every push. Every row of the product checklist in [`docs/ROADMAP.md`](docs/ROADMAP.md#what-finished-means-the-product-checklist) is done.

Phase 7: the online copy and the AI layer ([`docs/08-deployment-ai.md`](docs/08-deployment-ai.md)).

The online copy runs at https://strainscope.streamlit.app and the interactive figures are published at https://akannan2987.github.io/strainscope/ (both since 2026-10-12).

After Phase 7 came a small fix ([Handbook Stage 12.1](docs/HANDBOOK.md#stage-121-fix-for-small-language-models-the-model-check-and-clearer-suggestions)), listed under *Fixed*, then Phase 7b, the MCP server ([`docs/08b-mcp-server.md`](docs/08b-mcp-server.md)), and last Phase 8, packaging and release ([`docs/09-packaging.md`](docs/09-packaging.md)), each under headings of its own.

### Added (Phase 7b, the MCP server)
- `src/strainscope/mcp_server.py`: a **Model Context Protocol server** through which AI assistant apps (Claude Desktop, Claude Code and others) use StrainScope's results. Nine read-only tools, each a thin door onto the service layer: `ask_docs`, `ask_data`, `ask_graph`, `describe_database`, `query_database` (one `SELECT` or `WITH` behind the fifth guard and the console's four, at most 200 rows), `get_signature`, `rank_strain`, `explain_strain` and `shortlist`. Input is checked (a strain id like STRAIN_0485 that exists, questions of 1 to 300 characters, numbers within their limits), and a refusal reaches the app as a tool error with its sentence. Every tool is marked read-only with MCP tool annotations; anything a tool prints goes to stderr, never to stdout, which carries the protocol; the server's instructions tell the app that the data is simulated. No tool contacts a language model.
- The call log, `data/processed/mcp_calls.log`: one JSON line per call (the time in UTC, the tool, its inputs cut at 300 characters, the outcome, the seconds taken, and the row count for a query), never the result. A log that can't be written never stops a tool; `STRAINSCOPE_MCP_LOG` can point it elsewhere.
- The commands `python src/strainscope/mcp_server.py tools` (the tools and their inputs), `call` (one tool, run here, printed as JSON), `check` (starts the server as a separate program and talks to it over stdio, the way an app does) and `config` (the settings for Claude Desktop and the `claude mcp add` line for Claude Code, with this computer's paths). `tools`, `call` and `config` work without the `mcp` package.
- `tests/test_mcp.py` (40 tests): the tools and their numbers, every kind of refused input, no model contacted, plain JSON results, the log, stdout kept clean, the command line, and a real MCP session, in-process and over stdio. 409 tests in all.
- `figures/make_phase7b_figures.py`: one socket for many apps, three doors onto one service layer, the nine tools and their checks, one question in an app with its two tool calls (computed), and `docs/interactive/mcp_explorer.html` (each tool's description, input schema, a real call and its result, two refusals, the log), with a card on `docs/index.html`.
- `docs/08b-mcp-server.md`, the phase guide, and Phase 7b terms in `docs/GLOSSARY.md` (MCP server, host and client, tool, input schema, tool annotations, refusal, stdio, transport, JSON-RPC, handshake, call log, UTC, MCP Inspector, Node.js, absolute path).

## [0.3.0] - 2026-10-12: usable by anyone

Phases 6 and 6b, released together: the app and Ask StrainScope. Someone who has never opened a terminal can now explore the results, score their own strains, question the data and find any explanation ([why this tag](docs/ROADMAP.md#version-tags)).

### Added
- **Phase 6b: Ask StrainScope, the documentation assistant** ([`docs/07b-docs-assistant.md`](docs/07b-docs-assistant.md)).
  - `src/strainscope/ask.py`: questions about the project answered from its own documents. Every guide, the README, every glossary entry (each its own section) and the docstrings in `src/` and `app/` are split into sections at their headings (never inside code blocks) and searched in passages of about 120 words, with TF-IDF word weights (scikit-learn, no download), headings counted three times, filler words dropped, word forms matched ("strains" finds "strain") and code docstrings counting 0.8 so a guide wins a tie. Program output and diagrams aren't searched, and example questions quoted in the guides are blanked. A gate of four checks runs before anything is shown: instructions to the assistant are refused unsearched; a question with half or more of its words in no document is refused, naming them; a best match below 0.12 is refused; otherwise the question is answered when the passages found contain at least 75 % of its words, and shown as *closest* when they don't. Misspelt words are read as a close word the documents use, and said so. Answers show the best passage of the three best sections, word for word, with links; "you might also ask" suggestions come from similar sections elsewhere. Optional written answers (`STRAINSCOPE_ASK_BACKEND=local` for Ollama on the same computer, `hosted` for an OpenAI-compatible provider with its key in `.env`): only for answered questions, from the question and up to three passages only, citations required (otherwise not shown), a local model never reached through a proxy. Commands: a question, `--full`, `--golden`, `--stats`, `--no-write`.
  - `app/views/ask.py`: the *Ask StrainScope* page (under Home): starter questions as buttons, the verdict, the passages with working links and their pictures, the whole section on request, follow-up suggestions as buttons, and a switch for written answers when one is set up. Linked from Home.
