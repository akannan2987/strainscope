StrainScope · Phase 3 — integration explorer

Simulated data, disclosed as such. Built by figures/make_phase3_figures.py from artifacts/integration/; works offline.

1. Strains on the DIABLO map — hover any dot; switch the view with the buttons

Every dot is a strain. Effective strains (green) of every kingdom sit to the right on component 1 — the shared 'weapons' axis. Compare the gene-based and chemistry-based views: they tell the same story, which is exactly what DIABLO asks of them.

2. The signature, feature by feature — hover for stability and biology

Colours say whose weapon each feature is (blue bacteria, green fungi, gold yeast, purple oomycete, teal shared); light grey marks decoys. Component 1 is the signature to read; component 2 is kept for the 2-D map and mixes in decoys — notice how much lower their stability is.

3. Genes × chemistry correlations — hover any square

Bright red squares are pairs that rise and fall together. The strongest ones are each gene with its own product (ituA × iturin, pvdA × pyoverdine …). This table seeds the Phase 5 knowledge graph.

4. Every approach on one honest scale (balanced error rate; lower is better)

All Python rows share exactly the same folds. The DIABLO row comes from R with its own seeded folds, so compare it to the others to about ±0.01.
