StrainScope · Phase 4: model explorer

Simulated data, disclosed as such. Built by figures/make_phase4_figures.py from artifacts/model/; works offline.

Model card in one line: Elastic net logistic regression (settings {'C': 0.2}), calibrated · cross-validated balanced error 0.128 · AUC 0.948 · of the top 50 ranked strains, 47 are truly effective (chance: 12.1). Intended use: rank candidate microbial strains for further testing; research use.

1. Every model on the same folds (balanced error rate; lower is better)

Hover a bar for every score. Diamonds show each model when it flags strains whose probability beats the 24 % base rate instead of 50 %, which is fairer to models whose probabilities rarely climb high. The elastic net wins either way.

2. Calibration: does the model mean what it says?

Each point is a bin of predictions. On the dashed line, "30 %" comes true 30 % of the time. The raw model (red) says too much (the price of up-weighting the rare winners); the calibrated model (green) hugs the line.

3. What the winning model relies on (hover any bar)

Colours say whose weapon each feature is (blue bacteria, green fungi, gold yeast, purple oomycete, teal shared, dark = the kingdom label); light grey = decoy. The kingdom label tops the list because every feature is read relative to its kingdom's average, so scrambling the label makes every yardstick wrong.

4. Every strain: measured suppression vs predicted probability

Click a kingdom in the legend to hide or show it. Dots ringed in red are the strains the model gets wrong in most repeats. Almost all sit close to the 65 % line, where a strain's label depends on a few points of measurement noise.
