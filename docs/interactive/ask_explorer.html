StrainScope · Phase 6b: Ask StrainScope explorer

How the documentation assistant scores questions against 1002 sections of the project's own documents. The guide is docs/07b-docs-assistant.md.

The golden questions: how well each one matched

Each dot is one question from tests/golden_questions.csv; its colour is what Ask StrainScope did with it. Hover a dot for the question and its best section. The dashed line is the threshold: below 0.12 a question is refused; above it, it's answered when at least 75% of its words are in the passages found.

One question, every section

Pick a question from the menu to see the eight best-matching sections and their scores. Blue: a guide's section; purple: a glossary entry; grey: a code docstring (its score counts 80%, so a guide wins a tie).
